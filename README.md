# Messenger

> An open source messaging application built SvelteKit, shadcn/ui (Svelte), daisyUI, and more! 🌟

## Getting started

1. Clone the repository.

```sh
git clone git@github.com:ap0nia/messenger
```

2. Open the project.

```sh
cd messenger
```

3. Install dependencies.

```sh
bun install
```

4. Start the development server for the web application.

```sh
bun dev:web
```

## Project

This project is built with the following tools and dependencies.

- [SvelteKit](https://svelte.dev/)
- [shadcn-svelte](https://next.shadcn-svelte.com/)
- [daisyUI](https://daisyui.com/)
